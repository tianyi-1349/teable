## Summary

Apple's source style in `awesome-design-md` is photography-first, highly restrained, and driven by quiet hierarchy instead of decorative UI chrome.

## Key Signals Preserved For This Repo

- Refined, restrained, highly legible visual hierarchy
- Careful spacing and clean grouping
- Subtle surfaces with low visual noise
- Strong readability in detail and form-heavy interfaces
- Controlled emphasis rather than aggressive accent usage

## Local Adaptation Notes

- In this repo, Apple style is treated as a product UI influence, not a marketing-page clone target.
- We use it primarily for `record detail`, `form`, `settings`, and `side panel` surfaces.
- We do not import Apple-style wide hero spacing or photography-led landing-page composition into dense workflow pages.
